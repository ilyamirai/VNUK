# Telegram P2P Trading Monitor Bot

Telegram бот для мониторинга позиций на P2P рынке Telegram Wallet с интеграцией FunPay.

## Возможности

### Мониторинг USDT
- **Двойной мониторинг банков**: Одновременное отслеживание позиций в СБП и Сбербанке
- **Умное объединение уведомлений**: Если событие происходит в обоих банках одновременно, бот отправляет одно объединенное уведомление
- **Уведомления о позиции**: Мгновенное оповещение при изменении позиции с топ-1
- **Контроль разрыва**: Уведомление когда разрыв со 2 местом превышает 0.1%
- **Возврат на топ**: Уведомление о возвращении на 1 место

### Мониторинг криптовалют
- Отслеживание позиций для: TON, BTC, ETH, NOT
- Те же функции что и для USDT

### Проверка позиций
- Команда "Позиции Mirai" показывает текущие позиции по всем монетам
- Интеграция курса FunPay для USDT
- Расчет спреда относительно рынка

### Фильтры
- **Оптимальное предложение**: Онлайн + минимум ≤30,000 RUB + автопринятие
- **Верификация**: Только проверенные/доверенные продавцы
- **Сумма ордера**: Фильтр по желаемой сумме
- **Методы оплаты**: СБП, Сбербанк, Тинькофф, Альфа-Банк, Райффайзен

## Технологии

- **Python 3.13**
- **python-telegram-bot**: Telegram Bot API
- **pyTelegramWalletApi**: Telegram Wallet P2P API
- **BeautifulSoup4**: Парсинг FunPay
- **ThreadPoolExecutor**: Параллельная обработка позиций

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd WalletParse
```

2. Установите зависимости:
```bash
pip install python-telegram-bot beautifulsoup4 requests selenium-wire
pip install pyTelegramWalletApi
```

3. Получите Telegram Wallet API токен:

   **Вариант A (Автоматически):**
   ```bash
   python auto_token.py
   ```
   Скрипт будет автоматически обновлять токен каждые 5 минут. Запустите его в отдельном окне/процессе.

   **Вариант B (Вручную):**
   - Создайте файл `token.txt` с вашим Telegram Wallet API токеном

4. (Опционально) Создайте `funpay_cookies.txt` с куками для авторизации на FunPay

5. В `telegram_bot.py` замените `BOT_TOKEN` на токен вашего бота от @BotFather

## Запуск

**Основной бот:**
```bash
python telegram_bot.py
```

**Автообновление токена (опционально, в отдельном окне):**
```bash
python auto_token.py
```

## Особенности реализации

### Объединение событий
Мониторинг проверяет оба банка последовательно каждые 10 секунд. Если обнаруживает одинаковое событие (например, падение на 2 место) в обоих банках, отправляет одно сообщение вместо двух.

### Мультипоточность
Команда "Позиции Mirai" использует ThreadPoolExecutor для параллельной обработки 5 монет, что ускоряет выполнение в ~5 раз.

### Управление состоянием
Для каждого банка отслеживается независимое состояние:
- `last_position` - последняя известная позиция
- `notified` - флаг уведомления о падении с 1 места
- `gap_notified` - флаг уведомления о большом разрыве
